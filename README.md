# VidEarn

VidEarn is a video-sharing platform concept for short and long videos, with a future creator monetization model.

## Current prototype
- Responsive homepage for mobile and desktop
- Sample video cards
- Video search and category filters
- Supabase email/password authentication and creator profiles\n- Real video upload to Supabase Storage (500 MB cap)\n- Upload moderation queue; only approved public videos appear in the public feed\n- Referral code capture and personal invite links
- Referral system section (activation planned)

## Run
Open `index.html` in a modern web browser. No build tools are required.

## Development roadmap
1. User accounts and creator profiles
2. Real video uploads, storage, transcoding and playback
3. Likes, comments, subscriptions and content reporting/moderation
4. Referral links/codes, invite tracking and abuse prevention
5. Creator eligibility, advertising integration, revenue reporting and payouts

## Important
This repository currently contains a frontend prototype only. Accounts, video uploads, referral tracking, advertising revenue and payouts are not active yet. These require a secure backend, media storage, moderation and appropriate service/provider approvals.
